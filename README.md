# 🎮 Rock Paper Scissors Game using Flask

A simple and interactive **Rock Paper Scissors** web application developed using **Python Flask**. Players can choose **Rock, Paper, or Scissors**, play against the computer, and keep track of the scores.

---

## 📌 Project Description

This project is a web-based implementation of the classic **Rock Paper Scissors** game. The user selects one of the three options, and the computer randomly selects its choice. The application compares both choices, displays the winner, and updates the scoreboard.

The project uses:
- **Python** for backend logic
- **Flask** as the web framework
- **HTML & CSS** for the user interface

---

## ✨ Features

- 🎮 Play Rock, Paper, or Scissors
- 🤖 Random computer choice
- 🏆 Automatic winner detection
- 📊 Live score tracking
  - Player Score
  - Computer Score
  - Tie Score
- 🎨 Attractive responsive interface
- ⚡ Fast and lightweight

## 📥 Installation

### Step 1: Clone or Download the Project

Download the project folder or clone it using Git.

```
git clone https://github.com/yourusername/rock-paper-scissors-flask.git
```

---

### Step 2: Open Terminal

Navigate to the project folder.

```
cd RockPaperScissors
```

---

### Step 3: Install Flask

```

```

---

```
python app.py
```

---

### Step 5: Open Browser

Visit:

```
http://127.0.0.1:5000
```

## 🎯 How to Play

1. Open the website.
2. Click on:
   - 🪨 Rock
   - 📄 Paper
   - ✂️ Scissors
3. The computer randomly chooses one option.
4. The result is displayed:
   - 🎉 You Win!
   - 💻 Computer Wins!
   - 🤝 It's a Tie!
5. The scoreboard updates automatically.

---

## 🧠 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same choices result in a Tie
