# 🎮 Rock Paper Scissors Web Game

A simple and interactive **Rock Paper Scissors** web application built using **Python** and **Flask**. The game allows users to play against the computer, displays the game result, and maintains a live scoreboard for wins, losses, and ties.

---

# 📖 Project Overview

Rock Paper Scissors is one of the most popular hand games played worldwide. This project recreates the game as a web application using the Flask framework. The user selects either **Rock**, **Paper**, or **Scissors**, and the computer randomly chooses one of the three options. The application then determines the winner according to the game rules and updates the scoreboard.

The project features a modern animated interface with colorful buttons, smooth hover effects, and a responsive layout that works on both desktop and mobile devices.

# 🎮 How to Play

1. Open the application in your browser.
2. Choose one of the following:
   - 🪨 Rock
   - 📄 Paper
   - ✂️ Scissors
3. The computer randomly selects its choice.
4. Both choices are displayed.
5. The application determines the winner.
6. The scoreboard updates automatically.
7. Click **Play Again** to continue playing.

---

# 🧠 Game Rules

- 🪨 Rock beats ✂️ Scissors
- ✂️ Scissors beats 📄 Paper
- 📄 Paper beats 🪨 Rock
- If both players choose the same option, the game is a Tie.

---

# 📊 Scoreboard

The game keeps track of:

- 🏆 Player Score
- 💻 Computer Score
- 🤝 Tie Score

The scoreboard updates after every round.

---

# 💻 How the Application Works

1. The user selects Rock, Paper, or Scissors.
2. Flask receives the selected option using the POST method.
3. Python randomly generates the computer's choice.
4. The program compares both choices.
5. The winner is decided based on the game rules.
6. Scores are updated.
7. The updated result is displayed on the webpage.
